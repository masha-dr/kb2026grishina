описание программы GitHub User Finder- это простое desktop-приложение для поиска и сохранения пользователей GitHub. Программа позволяет искать пользователей, добавлять их в избранное, а также сохранять данные в JSON файл.

Возможности программы:

Поиск пользователей GitHub;
Отображение найденных пользователей в виде списка;
Автоматическое сохранение данных в JSON файл;
Загрузка данных из JSON файла при запуске;

Валидация вводимых данных

Проверка корректности ввода:
Поле ввода не должно быть пустым;
При добавлении в избранное, должен быть выбран пользователь;

Установка и запуск

Требования:
Python 3.6 или выше
Стандартная библиотека Python (tkinter, requests,  json, os)

Запуск программы:
Сохраните файл main.py в любую папку
Откройте терминал/командную строку
